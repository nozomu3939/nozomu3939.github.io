SNSで営業リストを作る方法｜Instagram・X・TikTokから見込み客を探す手順と注意点

Instagram・X・TikTok・YouTube・LinkedInなど、SNSから営業リストを作る方法を解説。SNSリードの価値、媒体ごとに向いている業種、取れる項目、作り方の手順、DMの注意点まで、営業の実務目線でまとめました。

編集：Lasone Data編集部 ／ 公開：2026-09-28 ／ 更新：2026-09-28

この記事の要点

  • SNSで発信している事業者は、集客や認知に積極的で、名簿業者のリストに載っていない見込み客が多くいます。
  • Instagramは店舗・美容・EC、XはIT・個人事業主、LinkedInは外資・ITなど、媒体ごとに向いている業種が違います。
  • 連絡前に、媒体の規約と窓口の用途・営業拒否の表示を確認します。公式窓口でも営業利用が許されるとは限りません。

SNSから営業リストを作る価値

  • 名簿にいない見込み客がいる：開業したばかりの店舗、個人で活動する事業者、D2Cブランドなどは、企業データベースに載っていないことが多い層です。
  • 発信＝意欲のサイン：投稿を続けている事業者は、集客や売上に積極的です。新しい施策の提案を聞いてもらいやすい傾向があります。
  • 規模と勢いが数字で見える：フォロワー数、投稿頻度、いいねやコメントの数から、事業の規模や伸び方の目安が分かります。

媒体ごとの向き・不向き

SNS見つけやすい相手向いている商材の例
Instagram飲食店、美容サロン、アパレル、EC・D2C集客支援、予約システム、撮影、物流
X（旧Twitter）IT企業、スタートアップ、個人事業主SaaS、開発、採用支援、広報支援
TikTok若年層向けの店舗・ブランド動画制作、インフルエンサー施策、EC
YouTube教育、コンサル、メーカー、専門家動画編集、広告運用、講座販売の支援
LinkedIn外資系企業、IT、人事・経営層BtoBのSaaS、人材、コンサル

SNSから取れる主な項目

項目営業での使い方
アカウント名・プロフィール文業種や事業内容の判断
フォロワー数事業規模・影響力の目安
投稿数・最終投稿日活動しているかどうかの確認
エンゲージメント（いいね・コメント）ファンの熱量、施策の成果の目安
プロフィールのリンク先公式サイトや問い合わせ窓口を見つける

取れる項目は媒体によって異なります。

SNSで営業リストを作る手順

  1. ターゲットの発信内容を決める：業種名、地域名、ハッシュタグなど、ターゲットが投稿やプロフィールに書きそうな言葉を洗い出します。
  2. 媒体を選んで集める：業種に合うSNSを選び、キーワードやハッシュタグでアカウントを集めます。
  3. 活動中のアカウントに絞る：最終投稿日が古いアカウントや、明らかに個人の趣味アカウントを除きます。
  4. 公式サイトとひもづける：プロフィールのリンク先から会社名・連絡先を特定し、法人リストと統合します。
  5. 規模と熱量で優先順位をつける：フォロワー数やエンゲージメントで並べ、商材に合う規模の事業者から連絡します。

DMで営業してもいい？

SNSのDMでの一斉営業はおすすめしません。多くのSNSは規約でスパム的なメッセージを制限しており、アカウントの制限や凍結につながるおそれがあります。また、相手にとってもプライベートな受信箱に営業が届く形になり、印象が悪くなりがちです。

SNSは「見つける」ために使い、連絡先は公式サイトで確認し、窓口の用途・営業拒否の表示・適用法令を確かめてから判断します。そのとき「Instagramの〇〇の投稿を拝見して」と具体的に伝えると、定型文との違いが伝わります。

注意点

  • 個人のアカウントは個人情報として扱う：個人で活動している人のアカウント情報は、個人情報にあたる可能性があります。利用目的を明確にしましょう。
  • 各SNSの規約を確認する：SNSごとに情報の取得方法や利用について規約があります。
  • 公開情報だけを使う：鍵アカウントや非公開の情報を集める行為は避けましょう。

よくある質問

SNSから営業リストを作るのは違法ですか？

公開されている情報を確認して営業先を探すこと自体は、一般に直ちに違法になるものではありません。ただし、個人のアカウント情報は個人情報にあたる可能性があり、各SNSの規約で取得方法や利用方法が制限されている場合もあります。規約を確認し、公開情報の範囲で扱うことが大切です。

InstagramとX、どちらが営業リストに向いていますか？

相手の業種によります。飲食店や美容サロン、ECなど見た目で集客する事業者はInstagramに多く、IT企業やスタートアップ、個人で活動する専門家はXに多い傾向があります。

SNSのDMで営業してもいいですか？

DMでの一斉営業はおすすめしません。SNSの規約でスパム的なメッセージが制限されており、アカウントの制限につながるおそれがあります。SNSで見つけた相手には、公式窓口の用途と営業拒否の表示を確認し、営業連絡を受け付ける窓口を選びます。

フォロワーが多いアカウントを優先すべきですか？

商材によります。高額な商材なら規模の大きいアカウント、小規模事業者向けの商材ならフォロワーが数百〜数千程度の成長途中のアカウントのほうが決裁も早く、相性がいいこともあります。
